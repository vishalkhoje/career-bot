2. Detailed Agent Workflow

1
Cache Check: Normalizes query and checks SQLite for identical previous answers. $0.00 cost path.
2
Intent Classification: GPT-4o-mini decides if the query needs simple facts or complex reasoning.
3
Retrieval Layer: Hybrid Search (BM25 + Vector) fetches top 20 chunks, FlashRank re-ranks to top 10.
4
Agent Reasoning: Strategic Planner breaks analytical tasks into logical steps for deeper analysis.
5
Critic Review: Quality Control agent verifies the final output against the context to eliminate hallucinations.
